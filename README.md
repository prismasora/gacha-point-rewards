# トキメキくじ — WEBガチャMVP

会員制WEBガチャとポイ活連動を、実際に操作できるレスポンシブな静的プロトタイプとして実装しています。

## 体験できる機能

- チケット残高の表示とブラウザ内保存
- 1回・10回・100回ガチャ、消費前確認、抽選演出、結果表示
- ラストワン残数の更新
- デイリーボーナス／ミッション達成によるチケット獲得
- 獲得景品BOXと景品交換フォーム
- デスクトップ／タブレット／モバイル対応
- キーボード操作、ダイアログ、ライブリージョン、Reduced Motion対応

## 注意

現時点は企画提案用のフロントエンドMVPです。認証、決済、確率・在庫のサーバー管理、広告成果通知、配送管理は本番開発でバックエンド接続が必要です。
